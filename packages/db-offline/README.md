# Offline Database

`@expense-tracker/db-offline` supplies Drizzle/SQLite repositories, PowerSync
integration, and isolated web, mobile, and desktop database drivers.

See [docs.md](./docs.md) for schema and synchronization contracts and
[usage-guide.md](./usage-guide.md) for platform setup.

```sh
pnpm --filter @expense-tracker/db-offline check-types
pnpm --filter @expense-tracker/db-offline build
```
